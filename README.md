## Любимый рабочий сетап и шорткаты



Шорткаты, которые я часто использую:

* Копировать: <kbd>Ctrl</kbd> + <kbd>C</kbd>
* Вставить: <kbd>Ctrl</kbd> + <kbd>V</kbd>
* Отменить последнее действие: <kbd>Ctrl</kbd> + <kbd>Z</kbd>
* Переключение между окнами: <kbd>Alt</kbd> + <kbd>Tab</kbd>

 > [!WARNING]
 > При настройке окружения могут возникать ошибки. Их не нужно бояться — это часть обучения! :)

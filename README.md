## 5
Для клонирования и локального запуска репозитория выполните:

# 1. Клонирование репозитория
git clone https://github.com/username/my-portfolio.git

# 2. Переход в папку проекта
cd my-portfolio

# 3. Открытие в редакторе
code .
Для быстрого запуска локального сервера в VS Code нажмите сочетание клавиш Alt + L, затем Alt + O (расширение Live Server).

[!WARNING] Не запускайте файл двойным кликом из проводника Windows! Пути к скриптам при протоколе file:/// могут работать некорректно. Используйте только локальный веб-сервер.
